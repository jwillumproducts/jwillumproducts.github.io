How to import journal entries into QuickBooks Online from Excel (template + checklist)

Import journal entries into QuickBooks Online from Excel or Google Sheets: the columns QuickBooks expects, a pre-import checklist, self-check formulas, and what to do if you only see Spreadsheet Sync.

Published 14 November 2026 · Updated 14 November 2026

Short answer: put one journal line per row with the columns Journal No., Journal Date, Account Name, Description, Debits and Credits. Lines that share a Journal No. form one entry, and each entry must balance. Save the sheet as CSV, then in QuickBooks Online go to Settings ⚙ → Import Data → Journal Entries. Most failed imports come from an unbalanced entry, an account name that doesn't match exactly, or a date stored as text, so check those three first.

1. Set up the columns

These are the fields Intuit lists for journal entry imports. The column names in your file don't have to match exactly, because you map them on the import screen, but keeping these names makes mapping a one-click job.

ColumnRequired?What goes in it
Journal No.YesThe entry number. Every line of the same entry gets the same number, e.g. PR-2026-10.
Journal DateYesOne date per entry, in your company's format (US: 10/31/2026; UK, CA, AU: 31/10/2026).
Account NameYesExactly as in your chart of accounts. Sub-accounts as Parent:Sub.
DescriptionRecommendedMemo for the line. Makes the entry easy to find later.
DebitsYesPositive number, plain digits: 1250.00. Leave empty on credit lines.
CreditsYesPositive number. Leave empty on debit lines.
NameFor A/R and A/P linesThe customer (Accounts Receivable) or vendor (Accounts Payable).
Class, LocationOptionalTurn on class or location tracking in QuickBooks first.

2. Enter one line per row

Example (illustrative numbers): a monthly payroll summary entry has four lines that share one Journal No. and one date:

Journal No.,Journal Date,Account Name,Description,Debits,Credits
PR-2026-10,10/31/2026,Payroll Expenses:Wages,October payroll,4200.00,
PR-2026-10,10/31/2026,Payroll Expenses:Taxes,October payroll,321.30,
PR-2026-10,10/31/2026,Payroll Liabilities,October payroll,,642.60
PR-2026-10,10/31/2026,Checking,October payroll,,3878.70

Debits 4,521.30 = credits 4,521.30, so the entry balances. Never put a debit and a credit on the same line; give each its own row.

3. Pre-import checklist

  1. Each Journal No. balances on its own, to the cent. A file that balances overall can still have one entry that is 0.01 off.
  2. Each entry has at least two lines and only one date.
  3. Account names match the chart of accounts exactly: same spelling, no extra spaces, sub-accounts as Parent:Sub. Intuit's help says using only the sub-account name gives a “Line Account Invalid” error.
  4. Account numbers are turned off during the import (Settings → Account and settings → Advanced → Chart of accounts), as Intuit recommends. Turn them back on afterwards.
  5. New accounts exist already. The import doesn't create accounts.
  6. A/R and A/P lines have a Name (customer or vendor).
  7. Amounts are plain positive numbers: no $, no thousand separators, at most 2 decimals. Round each line before you total.
  8. Dates are real dates in one format, not text. A date that Excel left-aligns is usually text.
  9. Row 1 is the header. QuickBooks uses the first row for mapping, so data in row 1 is not imported.
  10. Less than 1,000 rows per file, and no empty rows at the end (delete the rows, don't just clear them).
  11. Journal numbers aren't already used, or turn off “Warn if duplicate journal number is used” for the import, as Intuit notes.

4. Check it with formulas (free)

Add these helper columns next to your data, with the lines in rows 2–999 and columns A–F as above. They work in Excel, Google Sheets and LibreOffice:

CheckFormula (row 2, fill down)
Journal difference (should be 0)=ROUND(SUMIF($A$2:$A$999,A2,$E$2:$E$999)-SUMIF($A$2:$A$999,A2,$F$2:$F$999),2)
Lines in this journal (should be ≥ 2)=COUNTIF($A$2:$A$999,A2)
Date is a real date=ISNUMBER(B2)
Account exists (names pasted on a sheet called Accounts)=COUNTIF(Accounts!$A:$A,TRIM(C2))>0
Both debit and credit on one line=AND(N(E2)<>0,N(F2)<>0)

A text date can be converted with =DATEVALUE(B2) and then formatted as a date.

5. Save as CSV

  • Excel: File → Save As → CSV UTF-8 (Comma delimited). Only the active sheet is saved, so select the sheet with the journal lines first.
  • Google Sheets: File → Download → Comma-separated values (.csv), also for the current sheet only.
  • Open the CSV in a text editor once. Amounts should look like 1250.00, without quotes around thousand separators.

6. Import in QuickBooks Online

  1. Settings ⚙ → Import Data → Journal Entries.
  2. Select Browse and choose your CSV. (The screen also has Download a sample file.)
  3. Map your columns to the QuickBooks fields, select Next, fix anything it flags, then Start import.
  4. Start with one small journal. When it imports cleanly, import the rest.

7. Check the result

Run the Journal report for the date range and compare the total debits with your spreadsheet. If a line is wrong, open the journal entry and edit it. Imported journal entries are ordinary journal entries in QuickBooks.

If Import Data only offers Spreadsheet Sync

Intuit's import FAQ now says some accounts are only offered Spreadsheet Sync (“If the only option provided to import with is Spreadsheet Sync…”). Spreadsheet Sync is an Excel and Google Sheets add-in that comes with QuickBooks Online Advanced and Intuit Accountant Suite. Intuit's journal entry import article (updated August 2026) still describes the CSV upload, and users in a September 2026 thread said journal CSVs can still be imported without it. Which screen you see seems to depend on your account.

The rules are the same: balanced entries, exact account names and real dates. One QuickBooks Community thread traced a Spreadsheet Sync “invalid date” error to dates pasted as text. Run the checklist above, paste the lines into Spreadsheet Sync's Journal Entries template, set Post? to Yes and sync a small batch first.

FAQ

Can I import journal entries into QuickBooks Online from Excel?

Yes. Put one journal line per row with the columns Journal No., Journal Date, Account Name, Debits and Credits (Description, Name, Class and Location are optional), save it as CSV, then use Settings → Import Data → Journal Entries.

How many journal entries can I import at once?

Intuit says files must have less than 1,000 rows. Split bigger files, and keep all lines of one journal in the same file.

Do I need a template?

No. Intuit offers a sample file on the import screen. A template with built-in checks just catches unbalanced entries, wrong account names and text dates before QuickBooks rejects the file.

Can the import create new accounts?

No. Add new accounts to your chart of accounts first, then import.

What if Import Data only shows Spreadsheet Sync?

Intuit says some accounts are only offered Spreadsheet Sync, which comes with QuickBooks Online Advanced and Accountant. The same rules apply: balanced journals, exact account names and real dates. Paste the checked lines into its Journal Entries template.
