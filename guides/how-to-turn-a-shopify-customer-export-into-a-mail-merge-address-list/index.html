How to turn a Shopify customer export into a mail merge address list

Turn a Shopify customer export into a clean mail merge address list for US, UK, Canadian or Australian postcards and labels.

Published 28 September 2026 · Updated 13 October 2026

Want to send postcards, thank-you notes or catalogs to your Shopify customers? The customer list is already in Shopify Admin, but the export isn't shaped for a mail merge. There's no single "Full Name" field, the region is a code (CA, NSW) rather than a label your template expects, the column names don't match UK or Australian address conventions, and the file is full of emails, phone numbers, tags and marketing flags you don't want on a printed label.

Here's how to turn it into a clean address list by hand, ready for Word, Google Docs or your label software.

Step 1: Export customers with addresses

In Shopify Admin go to Customers → Export and include the default address fields. Keep an untouched copy. Note that the native export includes one address per customer (the default address), and names are in First Name and Last Name only. There's no separate "address first name" column.

Step 2: Build a Full Name column

Add a Full Name column. Assuming B is First Name, C is Last Name and D is Company, start with =TRIM(B2&" "&C2). For business customers with no personal name, use the Company value instead:

=IF(TRIM(B2&C2)="", D2, TRIM(B2&" "&C2))

Step 3: Rename columns to match the country

Mail-merge templates read better with local labels. Map the Shopify address columns like this:

  • US: Full Name, Company, Address1, Address2, City, State, ZIP, Country
  • UK: Full Name, Company, Address1, Address2, City, County, Postcode, Country
  • Canada: Full Name, Company, Address1, Address2, City, Province, Postal Code, Country
  • Australia: Full Name, Company, Address1, Address2, Suburb, State, Postcode, Country

Shopify's export gives codes for province and country, so expect NY and US, not full names. UK rows often have a blank province, which is fine: county is optional there.

Step 4: Remove incomplete rows

Filter out rows missing Address1, City or ZIP/postcode, and rows with no first name, last name or company. Put them on a separate sheet so you can fix them later instead of printing half an address.

Step 5: Remove private data you won't print

Delete Email, Phone, Default Address Phone, tags, notes, spend totals and marketing-consent columns. A mailing list you pass to a print shop or a helper should contain only what goes on the envelope.

Step 6: Remove duplicate addresses

The same household often appears twice (a guest checkout and an account, or two family members). To find them, build a comparison key: lowercase the name, company and address lines, strip punctuation, collapse spaces, uppercase the postcode and country, then join it all together. Sort by that key and keep the first row of each group.

Step 7: Filter by country and save

If you're mailing only within one country, filter to that country code (US, GB, CA or AU). Save as CSV UTF-8. If Excel garbles accented names, re-import through its UTF-8 CSV import.

A reminder: this cleans up the layout. It doesn't check that addresses can actually be delivered. Use your postal service's tools for that.
