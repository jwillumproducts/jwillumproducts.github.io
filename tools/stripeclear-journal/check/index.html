What the check shows

  • Count, gross, fees and net per reporting category (or Type)
  • Rows where gross − fee doesn't equal net
  • Activity, payouts and the balance change for the period
  • A warning when the file mixes currencies

FAQ

Is my file uploaded?

No. The file is read in this browser tab with the File API. The page makes no network requests with your data; you can confirm this in your browser's developer tools.

Which Stripe export does it read?

The Balance report's itemized balance change from activity CSV (columns such as reporting_category, gross, fee, net, currency) or the Dashboard balance transactions export (Type, Amount, Fee, Net, Currency). Decimal-comma files are handled too.

What does the free check not do?

It doesn't map categories to your accounts, split by payout or export a journal. StripeClear Journal does that and creates a QuickBooks Online journal CSV.

Is this affiliated with Stripe?

No. It is an independent tool. Stripe's own reports are the source of truth.
