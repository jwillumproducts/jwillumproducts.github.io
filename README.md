# JWillum products – website

Static site for https://jwillumproducts.github.io/ (GitHub Pages user site). No JavaScript, no trackers.
Products are sold on Gumroad: https://willumsen4.gumroad.com/

- `index.html`: landing page (inline CSS, JSON-LD structured data)
- `404.html`: not-found page
- `favicon.png`, `og-image.png` (1200×630 social preview), `img/` (real product screenshots)
- `robots.txt`, `sitemap.xml`, `llms.txt` (summary for AI answer engines)
- `.nojekyll`: serve files as-is

Not for publishing: `draft-old.html`, `preview-*.png` (local previews).
