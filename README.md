# JWillum products – website

Static site for https://jwillumproducts.github.io/ (GitHub Pages user site). Plain HTML and inline CSS: no JavaScript, no trackers, no external fonts.
Products are sold on Gumroad: https://willumsen4.gumroad.com/

- `index.html`: home page (links to all tools and guides)
- `tools/`: one page per tool, plus an index
- `guides/`: free step-by-step guides, plus an index
- `img/`: real screenshots of the tools
- `404.html`, `robots.txt`, `sitemap.xml`
- `llms.txt`, `llms-full.txt`: plain-text summaries for AI assistants
- `.nojekyll`: serve files as-is

Every tool is $8 one-time, runs offline in the browser, and needs no account. Contact: jwillum.products@gmail.com
